# Changelog

## 0.1.0 — Unreleased

- Add MikroTik RouterOS `.rsc` syntax highlighting for Zed.
- Highlight comments, strings, escapes, interpolation, variables, commands,
  properties, network addresses, numbers and durations.
- Provide bracket matching and indentation for nested blocks and expressions.
- Keep `#` inside strings distinct from comments, including after interpolation.

This first release provides structural syntax highlighting, not RouterOS
configuration validation, execution, completions or language-server features.
